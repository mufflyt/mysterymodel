# One panel per predictor, both allocations on the same axes

One panel per predictor, both allocations on the same axes

## Usage

``` r
mm_draw_splines(shapes, frame)
```

## Arguments

- shapes:

  An
  [`mm_splines()`](https://mufflyt.github.io/mysterymodel/reference/mm_splines.md)
  result.

- frame:

  The development rows, for the rug.

## Value

`invisible(NULL)`, after drawing.
