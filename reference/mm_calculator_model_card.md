# What the screen says about the model behind it

The adequacy verdict is on the face of the calculator rather than in a
footnote, because a model that is short of the sample its shape requires
produces predictions that are too extreme at both ends, and that is a
fact about every number the page displays.

## Usage

``` r
mm_calculator_model_card(model, threshold)
```

## Arguments

- model:

  A
  [`mm_model()`](https://mufflyt.github.io/mysterymodel/reference/mm_model.md).

- threshold:

  The risk the bands are relative to.

## Value

A Shiny tag.
