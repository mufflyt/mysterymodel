# Discrimination, calibration and accuracy for one set of predictions

Discrimination, calibration and accuracy for one set of predictions

## Usage

``` r
mm_metrics(p, y, basis, note = "")
```

## Arguments

- p:

  Predicted probabilities.

- y:

  0/1 outcome.

- basis:

  Label for the row.

- note:

  What produced it.

## Value

A one-row data frame.
