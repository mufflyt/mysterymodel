# The nomogram panel, with the check that lets it be shown

The nomogram panel, with the check that lets it be shown

## Usage

``` r
mm_calculator_nomogram_panel(drawn)
```

## Arguments

- drawn:

  The output of
  [`mm_calculator_nomogram()`](https://mufflyt.github.io/mysterymodel/reference/mm_calculator_nomogram.md),
  or `NULL`.

## Value

A Shiny tag, or `NULL`.
