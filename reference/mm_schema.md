# Record what a deployed prediction is allowed to receive

Record what a deployed prediction is allowed to receive

## Usage

``` r
mm_schema(project, dev)
```

## Arguments

- project:

  A
  [`mm_project()`](https://mufflyt.github.io/mysterymodel/reference/mm_project.md).

- dev:

  The development rows.

## Value

A list describing each predictor.
