# The exclusions, as a sentence for the note column

The exclusions, as a sentence for the note column

## Usage

``` r
mm_eligibility_note(e)
```

## Arguments

- e:

  An
  [`mm_evaluable()`](https://mufflyt.github.io/mysterymodel/reference/mm_evaluable.md)
  report.

## Value

A string, or `""` when nothing was excluded.
