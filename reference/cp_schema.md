# Record what a deployed prediction is allowed to receive

Record what a deployed prediction is allowed to receive

## Usage

``` r
cp_schema(project, dev)
```

## Arguments

- project:

  A
  [`cp_project()`](https://mufflyt.github.io/mysterymodel/reference/cp_project.md).

- dev:

  The development rows.

## Value

A list describing each predictor.
