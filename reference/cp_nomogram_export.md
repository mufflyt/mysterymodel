# Export the nomogram as vector and raster files

Export the nomogram as vector and raster files

## Usage

``` r
cp_nomogram_export(nom, out_dir, slug, width, height)
```

## Arguments

- nom:

  An `rms` nomogram.

- out_dir:

  Directory.

- slug:

  Study slug.

- width, height:

  Inches.

## Value

The paths written.
