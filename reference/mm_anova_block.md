# The row of an rms anova table belonging to one interaction block

The row of an rms anova table belonging to one interaction block

## Usage

``` r
mm_anova_block(table, pair)
```

## Arguments

- table:

  An [`rms::anova.rms()`](https://rdrr.io/pkg/rms/man/anova.rms.html)
  result.

- pair:

  The two predictor names.

## Value

The row index, or `NA_integer_`.
